# Supabase Edge Functions — ضاد

هذا المجلد يحتوي نسخ المصدر المقترحة لدوال الإدارة المرتبطة بالفرع التطويري.

## مهم
- هذه الملفات محفوظة في فرع `feature/admin-v2-phase-2` فقط.
- لم يتم نشرها إلى مشروع Supabase الحي.
- لا ترفع هذه الدوال إلى المشروع قبل مراجعة الاختبارات والموافقة الصريحة.
- لا تضع مفاتيح `service_role` أو أسرار OAuth في هذا المستودع.

## الإصلاحات المضمنة
- السماح للموظفين النشطين/المدعوين بالمرور من بوابة التحقق العامة، مع إبقاء إجراءات إدارة الموظفين ومساحات التخزين مقصورة على المالك.
- توحيد صلاحيات دور `admin` في استجابة `my_access`.
- السماح لدالة الإحصائيات للمالك والمدير المضمن مسبقًا، أو الموظف الذي لديه `permissions.analytics = true`، أو الموظف بدور `admin`.
- توجيه دعوات الموظفين إلى `/admin/` بدل الصفحة القديمة.
- إخفاء وحدات لوحة الإدارة التي لا تسمح بها صلاحيات الحساب.

## ملاحظات التحقق
- صلاحيات RLS الحالية لجدول `materials` تعتمد على `private.dhad_has_permission('files')` و`file_delete`، وهي متوافقة مع نموذج مشرف الملفات الحالي.
- جدول `admin_staff` كان فارغًا وقت المراجعة؛ لم تتم إضافة موظفين أو تغيير بياناته.
- لم يتم تغيير إعدادات Google OAuth أو قوائم Redirect URLs.
